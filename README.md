# Tic-Tac-toe-Game
A simple, responsive Tic-Tac-Toe (XO Game) built using HTML, CSS, and  JavaScript. The game is fully interactive with dynamic win detection, responsive layout using Flexbox &amp; VMIN units, and a clean user interface.



🎮 Features:
Playable 2-player Tic-Tac-Toe game.

Dynamic winner detection and result display.

Responsive design (works on Desktop & Mobile).

Clean UI using CSS Flexbox & Grid concepts.

Pure JavaScript logic (No external libraries).

🛠️ Tech Stack:
HTML5

CSS3 (Flexbox, VMIN units)

JavaScript (ES6)
